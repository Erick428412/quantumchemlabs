# quantumchemlabs
Quantum Chemistry Labs es una aplicación web desarrollada en Python con la librería Streamlit, diseñada para el modelado de moléculas orgánicas en 2D, analisis bioquimicos, toxicologicos y el cálculo de diversos valores estequiométricos, propiedades físicas y químicas, isomería y polaridades. Próximamente incorporará análisis y cálculos cuánticos avanzados mediante la librería Qiskit.
# Como ejecutar
Ejecutalo en tu navegador web de preferencia con el siguiente link: https://quantumchemlabs.streamlit.app/
