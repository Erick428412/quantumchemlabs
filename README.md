# quantumchemlabs
Quantum Chemistry Labs es una aplicación web desarrollada en Python con la librería Streamlit, diseñada para el modelado de moléculas orgánicas en 2D y el cálculo de diversos valores estequiométricos, propiedades físicas y químicas, isomería y polaridades. Próximamente incorporará análisis y cálculos cuánticos avanzados mediante la librería Qiskit.
